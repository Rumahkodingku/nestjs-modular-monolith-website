# Hero Image Generation Prompts

## Light Mode

Create a premium cinematic hero image for a B2B developer product about building production-ready backends with a NestJS modular monolith. Show an abstract architectural system made from a central structured core and several clearly separated, interconnected modules. Use distinct geometric layers and precise connection paths to suggest authentication and security, business modules, PostgreSQL data storage, API communication, logging, health monitoring, and observability without using literal interface panels, icons, labels, or readable text.

Compose the scene as a refined three-quarter isometric product visualization. Place the main modular structure inside the central 70 percent safe area, with balanced negative space and calm edges so the image remains strong when cropped with CSS `object-cover`. Make module boundaries immediately understandable, with a few restrained data-flow paths converging through the central core. The system should feel cohesive, maintainable, secure, and production-ready rather than futuristic or experimental.

Use a light palette matching a modern technical landing page: soft off-white `#f6f5f4` background, subtle warm-gray surfaces, near-black `#171214` structural details, and a single restrained Nest-inspired red accent `#d91f3d` applied to selected connection paths and small structural elements. Use soft directional studio lighting, realistic material depth, crisp edges, subtle contact shadows, and controlled contrast. Keep the result sophisticated, minimal, editorial, and credible for experienced backend engineers.

Output requirements: 1920x1080 pixels, 16:9 landscape composition, high detail, sharp central subject, consistent visual hierarchy, web-ready hero artwork. This image is the light member of a matched light and dark pair, so preserve the specified camera angle, object placement, scale, module geometry, connection paths, and crop-safe composition exactly for the dark version.

Do not include text, letters, numbers, code, logos, brand marks, watermarks, people, hands, laptops, monitors, dashboards, browser windows, terminal windows, fake user interfaces, generic floating cards, neon lighting, outer glows, cyberpunk styling, blue-purple gradients, AI-purple color schemes, excessive glassmorphism, clutter, or tiny decorative details.
